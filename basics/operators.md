# 演算子とは

**演算子**は、値の計算・比較・代入などを表す記号です。演算の対象となる値や式を**オペランド**と呼びます。

## 要点

- 演算子の意味は、対象の型によって異なる場合があります。
- 比較や論理演算の結果は`boolean`です。
- `&&`と`||`は、結果が確定すると右側の式を評価しません。

## 仕組み・特徴

| 分類 | 例 | 意味 |
| --- | --- | --- |
| 算術 | `+`、`-`、`*`、`/`、`%` | 加減乗除、剰余 |
| 比較 | `<`、`<=`、`>`、`>=`、`==`、`!=` | 大小や等しさの比較 |
| 論理 | `&&`、`||`、`!` | AND、OR、否定 |
| 代入 | `=`、`+=` | 値の代入、加算して代入 |
| 条件 | `条件 ? 値1 : 値2` | 条件に応じた値の選択 |

### 短絡評価 {#short-circuit}

`&&`は左側が`false`なら、`||`は左側が`true`なら、右側を評価しません。これを短絡評価と呼びます。`boolean`に使う`&`と`|`は両側を評価するため、同じ挙動ではありません。

## コード例

```java
String name = null;
boolean hasName = name != null && !name.isEmpty();
System.out.println(hasName); // false
```

`name != null`が`false`なので、`isEmpty()`は呼ばれません。

## 間違えやすい点

- `=`は代入、`==`は比較です。参照型同士の`==`は内容の比較ではありません。
- 整数同士の`5 / 2`は`2`です。整数のゼロによる除算は例外になります。
- `+`は文字列の連結にも使われます。`"値: " + 1 + 2`は`"値: 12"`になります。
- 優先順位が分かりにくい式には括弧を付けると、計算の意図が明確になります。
