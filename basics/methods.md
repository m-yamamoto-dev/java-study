# メソッドとは

**メソッド**は、名前を付けて呼び出せる処理です。入力を**引数**として受け取り、結果を**戻り値**として返すことができます。

## 要点

- 宣言側の引数を仮引数、呼び出し側で渡す値を実引数と呼びます。
- `void`は、戻り値を返さないことを表します。
- Javaの引数は、参照型を含めて値渡しです。
- 同じ名前で異なる引数のメソッドを定義することをオーバーロードと呼びます。

## 仕組み・特徴

### 値渡し {#pass-by-value}

呼び出し時には、実引数の値が仮引数へコピーされます。参照型では参照の値がコピーされるため、呼び出し元と同じオブジェクトを扱えます。ただし、仮引数に別の参照を再代入しても、呼び出し元の変数は変わりません。

### staticとインスタンスメソッド {#static}

インスタンスメソッドは特定のインスタンスに対する操作です。`static`メソッドはクラスに属し、`this`を持ちません。`static`メソッドでも、引数などで受け取ったオブジェクトを操作できます。

`static`フィールドもクラスに属します。各インスタンスに個別の値を持たせるフィールドとは異なります。

### オーバーロード {#overloading}

同じ名前でも、引数の型や数が異なれば、通常は別のメソッドを宣言できます。戻り値の型だけを変えてもオーバーロードにはなりません。

ただし、ジェネリクスの型引数だけを変えても宣言できない場合があります。例えば、`show(List<String> values)`と`show(List<Integer> values)`は、型消去後にどちらも`show(List)`となるため、同じクラスには宣言できません。

### 可変長引数 {#varargs}

`static int sum(int... values)`のように宣言すると、呼び出し側で複数の`int`を渡せます。メソッド内では`values`を`int[]`として扱います。可変長引数は最後の仮引数にだけ指定でき、通常は引数0個や既存の配列でも呼び出せます。`int...`と`int[]`だけの違いではオーバーロードできません。

## コード例

```java
class Example {
    static void change(int[] values) {
        values[0] = 20;
        values = new int[] {30};
    }

    public static void main(String[] args) {
        int[] original = {10};
        change(original);
        System.out.println(original[0]); // 20
    }
}
```

要素の変更は共有する配列に反映されますが、仮引数への再代入は`original`の参照を変えません。

## 間違えやすい点

- 参照を渡すことと、参照渡しという引数の仕組みは同じではありません。
- `static`メソッドからインスタンスフィールドへ、対象のインスタンスなしでアクセスすることはできません。
- オーバーロードと、継承したメソッドを置き換えるオーバーライドは別です。
