# 型変換とキャストとは

**型変換**は、ある型の値を別の型の値として扱うための変換です。**キャスト**は、`(int)`などの構文で変換先の型を明示することです。ここでは主にプリミティブ型の数値変換を扱います。

## 要点

- 代入や演算の際、型変換が自動で行われる場合があります。
- `long`から`int`などの変換には、通常キャストが必要です。
- 変換によって範囲や精度の情報が失われることがあります。

## 仕組み・特徴

### 拡大変換と縮小変換

| 種類 | 例 | 注意点 |
| --- | --- | --- |
| 拡大プリミティブ変換 | `int` → `long`、`int` → `float` | 自動で行えるが、常に精度が保たれるとは限らない |
| 縮小プリミティブ変換 | `long` → `int`、`double` → `int` | 通常はキャストが必要。値の情報を失う場合がある |

`int`から`float`への変換では、大きな整数を正確に表せない場合があります。拡大・縮小は、単にメモリサイズだけを表す言葉ではありません。

### 演算時の型 {#promotion}

`byte`、`short`、`char`同士の加算では、通常`int`として計算されます。また、整数同士の割り算は整数の結果になります。結果を後から`double`へ変換しても、失われた小数部分は戻りません。

## コード例

```java
int count = 10;
long wide = count;          // 自動で拡大変換
int truncated = (int) 3.9; // 小数部分を切り捨てて3

double integerResult = 5 / 2;       // 2.0
double decimalResult = (double) 5 / 2; // 2.5
```

最後の式では、割り算の前に片方を`double`へ変換するため、浮動小数点数の計算になります。

浮動小数点数から整数への変換で小数部分を取り除くときは、ゼロに向かって丸めます。例えば`(int) -3.9`は`-3`であり、`-4`にはなりません。NaNを`int`へ変換すると`0`になり、`int`の範囲を超える値や無限大は、符号に応じて`Integer.MIN_VALUE`または`Integer.MAX_VALUE`になります。

## 間違えやすい点

- キャストは値の安全性を保証しません。範囲外の整数を縮小すると、符号が変わることもあります。
- `boolean`と数値型の間ではキャストできません。
- `byte b = 10;`のような範囲内の整数定数の代入には、キャストが不要な場合があります。
- 文字列`"123"`を`int`へキャストすることはできません。`Integer.parseInt`などで解析します。
