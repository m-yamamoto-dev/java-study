# ラッパークラスとは

**ラッパークラス**は、[プリミティブ型](./primitive.md)の値をオブジェクトとして扱うためのクラスです。

例えば、`int` に対応するラッパークラスは `Integer` です。

```java
int number = 10;
Integer wrapped = number; // オートボクシング
```

## 覚えておきたいポイント

- ラッパークラスは参照型です。
- `Integer.parseInt("123")` のような便利なメソッドがあります。
- プリミティブ型とラッパークラスの間では、オートボクシングやアンボクシングが行われます。
