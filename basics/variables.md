# 変数とスコープとは

**変数**は、型と名前を持ち、値を保持するものです。**スコープ**は、その名前で変数を参照できるコード上の範囲を指します。

## 要点

- 宣言は変数の型と名前を定め、初期化は最初の値を与えます。
- メソッド内などで宣言する変数をローカル変数と呼びます。
- `final`変数は、一度値を代入すると再代入できません。

## 仕組み・特徴

### 宣言・初期化・代入

`int count = 10;`は宣言と初期化を同時に行います。その後の`count = 20;`は再代入です。変数に代入できる値は、その型によって制限されます。

### ローカル変数・フィールド・引数

| 種類 | 意味 | 初期値 |
| --- | --- | --- |
| ローカル変数 | メソッドやブロック内で宣言する変数 | 使用前に値の代入が必要 |
| フィールド | クラスに宣言する、状態を保持する変数 | 型に応じて`0`、`false`、`null`など |
| 仮引数 | メソッドが受け取る値を保持する変数 | 呼び出し時に渡した値 |

ブロック内のローカル変数は、原則として宣言した位置からそのブロックの終わりまで参照できます。スコープと、オブジェクトがメモリ上に存在する期間は別の概念です。

### finalと不変性 {#final}

`final`は変数への再代入を禁止します。参照先のオブジェクトまで不変にするものではありません。一般に定数と呼ばれる値には`final`を使いますが、言語仕様上の「定数変数」は、定数式で初期化したプリミティブ型または`String`型の`final`変数です。

### varによる型推論 {#var}

Java 10以降では、初期化子付きのローカル変数に`var`を使えます。`var count = 10;`の型はコンパイル時に`int`と決まり、後から文字列を代入できるようにはなりません。フィールドや通常のメソッドの仮引数・戻り値の型には使えません。`var value = null;`では型を決められないため、コンパイルエラーになります。

## コード例

```java
final int[] scores = {10};
scores[0] = 20; // 要素の変更は可能
System.out.println(scores[0]); // 20
// scores = new int[] {30}; // 再代入はコンパイルエラー
```

配列は可変ですが、`scores`に別の配列への参照を代入することはできません。

## 間違えやすい点

- ローカル変数は、宣言しただけでは使用できません。
- `final`は「宣言時に必ず初期化する」という意味ではありません。後から一度だけ代入することもできます。
- 同じ値への再代入でも、初期化済みの`final`変数には許されません。
